# Bookrithm
Simulador de algoritmos e estruturas de dados I, feito em flutter, multiplataforma, com objetivo em aprendizado.

# Build
  flutter build

  gera o output com binarios executaveis do sistema operacional sendo usado, caso seja necessário o build para android ou mac, é obrigatório instalar o android studio e /ou ter um computador MAC para compilar em xcode

# Acesso
Pode ser feito o download do binário em releases, e também pode ser acessado via https://yazuc.github.io/
